# POO_RMS_2026-2027

Repositorio para la asignatura de **Programación Orientada a Objetos** en la especialización de Python[cite: 1].

---

## 🛠️ Entorno de Desarrollo

Para trabajar en este proyecto se utiliza **Visual Studio Code** configurado con las siguientes extensiones[cite: 1]:

* **Python** *(Microsoft)*: Soporte oficial del lenguaje, ejecución de scripts y herramientas esenciales[cite: 1].
* **Pylance** *(Microsoft)*: Servidor de lenguaje de alto rendimiento con autocompletado inteligente y comprobación de tipos[cite: 1].
* **Python Debugger** *(Microsoft)*: Depuración paso a paso e inspección de variables[cite: 1].
* **Python Environments** *(Microsoft)*: Gestión unificada de entornos virtuales e intérpretes[cite: 1].
* **Ruff** *(Astral Software)*: Linter y formateador ultrarrápido para mantener el código limpio y siguiendo el estándar PEP 8[cite: 1].
* **autoDocstring** *(Nils Werner)*: Generación automática de docstrings para clases, métodos y funciones[cite: 1].
* **Error Lens** *(Alexander)*: Resaltado en línea de errores y advertencias directamente en el editor[cite: 1].
* **Spanish Language Pack** *(Microsoft)*: Interfaz de VS Code en español[cite: 1].
